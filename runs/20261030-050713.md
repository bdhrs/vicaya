Cause: searched the chant's distinctive first line rather than its title. Fix: preserve — search the opening syllables of an unidentified text, not its supposed name. Scope: global.
- [POSITIVE] Evidence: the 172-token dictionary attestation count settled the "is it a language" question with a number instead of an impression. Cause: romanising the whole text first, then querying the DPD `lookup` table per token. Fix: preserve as a standard method for pseudo-Pali texts. Scope: global.
- [WORKFLOW] Evidence: generic web search collapsed mid-run — DuckDuckGo returned zero for queries that had worked minutes earlier, and Bing returned unrelated results for Thai queries.
