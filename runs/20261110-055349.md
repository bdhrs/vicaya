## Improvement suggestions
- Suggest: `scratch-verify` should flag a gate whose timestamp precedes the first logged entry in its phase — resuming a slug whose prior session gated unworked phases currently passes silently, which is how this run inherited "passed" gates for work it had to redo.
- Suggest: Document that `--quiet` output is compacted to a human snippet and is not valid JSON, so it cannot be piped into a parser; several calls in this run failed silently on that assumption.
- Suggest: `search-library-folders` should emit a warning when the query contains an unbalanced apostrophe or quote rather than returning an empty list, since FTS5 rejects it and the failure currently looks identical to a genuine zero-hit.
- Suggest: In Phase 4a, name Europe PMC's REST endpoint (`ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:"..."&resultType=core`) as the fallback for abstracts and author lists when OpenAlex returns an empty abstract — it is reliable, needs no key, and resolved metadata OpenAlex could not for several papers here.
